Offline Media & Audio Engine

Jetpack Compose • Media3

Built an offline audio streaming application from scratch. Designed an index-based hidden list queue architecture ensuring deterministic playback history.

Kotlin Realm DB

A fully featured offline media application engineered from scratch, focusing on seamless audio pipelines, custom playback architectures, and native Android performance.

The Challenge

Standard music players often use a destructive item-removal queue mechanism. When a song finishes, the item is destroyed from the active playlist, making it impossible to smoothly navigate backward through the exact historical session without relying on a separate database query.

Architecture & Solution

To solve this, I engineered a custom index-based hidden list mechanism for the queue UI.

  • Non-Destructive Queue: We don't remove songs from the playlist anymore. Instead, the UI hides previously played items based on the current playing index.
  • Seamless Reversal: Going backwards natively retrieves the previous index directly from the active queue in memory, guaranteeing state accuracy.
  • Media3 Integration: Leveraged Google's ExoPlayer/Media3 for the audio rendering, ensuring background playback and notification controls stay perfectly in sync.
