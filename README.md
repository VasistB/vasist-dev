# Vasist Vamsi Bhukya — Android Engineer Portfolio

Production portfolio built with **React**, **Vite**, **Tailwind CSS**, **Lucide Icons**, **AOS**, and **GSAP** (ScrollTrigger animations & Pixel phone mockup transforms).

## 🚀 Quickstart

1. **Clone the repository:**
   ```bash
   git clone https://github.com/VasistB/vasist-portfolio.git
   cd vasist-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
